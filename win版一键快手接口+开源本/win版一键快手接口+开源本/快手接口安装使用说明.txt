快手极速版加密签名服务 · Windows 一键启动包

使用步骤：

1. 确保手机开启「开发者选项」和「USB调试」
2. 用数据线连接电脑
3. 首次使用运行：一键安装依赖（安装Python依赖）
4. 运行：一键推送.bat（推送Frida Server到手机）
   （每次重启手机后需重新运行）
5. 打开手机上的「快手极速版」App
6. 双击：start.bat
7. 看到 "Running on http://0.0.0.0:5000" 表示成功

可用接口：
  POST http://localhost:5000/encdata   { "data": "原始数据" }
  POST http://localhost:5000/sign      { "data": "参数字符串" }
  POST http://localhost:5000/nssig3    { "data": { "a":1 } }

注意：
- 需自行下载最新 frida-server 放入 assets/ 文件夹
- 下载地址：https://github.com/frida/frida/releases
- 选择：frida-server-xx.x.x-android-arm64.xz
- 解压后重命名为 frida-server-arm64

如有问题，请检查日志输出。
